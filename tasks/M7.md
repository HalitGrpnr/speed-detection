## Amaç

Bir bilirkişinin terminal bilmeden kullanabileceği, masaüstünde çalışan yerel bir
uygulama sunmak. Operatör tek bir çalıştırılabilir dosyaya/kısayola tıklar; tarayıcıda
`127.0.0.1` açılır; video yükler, noktaları tıklar, pipeline'ı başlatır, raporu indirir.
Hiçbir veri makineden çıkmaz (`CLAUDE.md` kural 1).

---

## Yaklaşım: FastAPI + Tarayıcı (MVP)

Teknik analiz §11.1'deki "MVP aşaması" yolu izlenir:

- **Arka yüz:** FastAPI (`127.0.0.1:<sabit-port>`). Tüm iş mantığı mevcut
  `src/` modülleridir; FastAPI yalnızca HTTP köprüsüdür.
- **Ön yüz:** Vanilla HTML/CSS/JS (`static/` klasöründen serve edilir). Harici
  CDN yok; bağımlılıklar `static/vendor/` altında yerel olarak taşınır.
  İnternetsiz adli makine için kritik.
- **Başlatıcı:** PyInstaller ile tek-klasör (`--onedir`) paket. Kullanıcı
  `SpeedDetection` ikonuna çift tıklar → arka planda sunucu başlar → tarayıcı
  otomatik açılır → kapanınca sunucu durur.
- **GPU/CPU:** Mevcut `YOLODetector` otomatik algılama zaten var; ayar sayfasında
  gösterilir.

**PySide6 / Tauri neden değil?** Bu fazda bilirkişiden onay alınamadan UI
şablonu değiştirilmez. Tarayıcı tabanlı yaklaşım çapraz platform, daha hızlı
iterasyon sağlar ve "olgun aşama"ya geçiş ileride tek `app.py` değişikliğidir.

## Operatör Akışı (§10 referansı)

```
1. Video yükle         → FPS + çözünürlük otomatik okunur, operatör doğrular
2. Kalibrasyon karesi  → zaman çizelgesi veya kare numarasıyla seç
3. Noktaları işaretle  → M6 önerileri otomatik yüklenir; operatör canvas'ta
                         onaylar / siler / ekler / kaydırır
4. Mesafe gir          → her nokta çifti için gerçek metre değeri (veya preset
                         "şerit 3.5 m")
5. Canlı RMS           → her değişiklikte re-projeksiyon RMS anında güncellenir
6. (Opsiyonel) saha    → ölçülen koordinat/mesafe girilebilir (Katman 3)
7. İşle                → tespit + takip + hız + overlay + rapor; ilerleme çubuğu
8. Sonuçları incele    → overlay video tarayıcıda oynatılır; PDF indirilir
```

## API Uç Noktaları

### Video

| Metot | Yol | Açıklama |
|-------|-----|----------|
| `POST` | `/api/video/upload` | Video dosyası yükle → `{video_id, fps, width, height, frame_count, sha256}` |
| `GET`  | `/api/video/{vid}/meta` | Kayıtlı meta veriyi döndür |
| `GET`  | `/api/video/{vid}/frame/{n}` | N. kareyi JPEG olarak döndür |
| `GET`  | `/api/video/{vid}/thumbnail` | Video ortasından küçük önizleme |

### Kalibrasyon

| Metot | Yol | Açıklama |
|-------|-----|----------|
| `POST` | `/api/video/{vid}/autoref` | Seçili karede `AutoProposer.propose()` çalıştır → `[ProposedPoint]` |
| `POST` | `/api/calibrate` | Kontrol noktaları + mesafeler → `{H, rms, confidence_layer, inlier_count}` |

### Pipeline

| Metot | Yol | Açıklama |
|-------|-----|----------|
| `POST` | `/api/pipeline` | Kalibrasyon + video → arka planda işle → `{job_id}` |
| `GET`  | `/api/job/{jid}/status` | `{state, progress_pct, eta_s, error}` — polling için |
| `GET`  | `/api/job/{jid}/report` | PDF raporu indir |
| `GET`  | `/api/job/{jid}/overlay` | Overlay videoyu indir |
| `GET`  | `/api/job/{jid}/results` | JSON özet (araç sayısı, hız tablosu) |

## Pydantic Şemaları (schemas.py)

```python
class VideoMeta(BaseModel):
    video_id: str
    fps: float
    fps_source: str          # "container" | "operator_override"
    width: int
    height: int
    frame_count: int
    sha256: str

class ControlPointIn(BaseModel):
    id: str
    pixel: tuple[float, float]
    world_m: tuple[float, float]
    source: str              # "auto" | "operator" | "site_measurement"

class CalibrateRequest(BaseModel):
    video_id: str
    frame_n: int
    control_points: list[ControlPointIn]

class CalibrateResponse(BaseModel):
    rms_m: float
    inlier_count: int
    confidence_layer: str
    homography: list[list[float]]   # 3×3
    planarity_warning: bool

class PipelineRequest(BaseModel):
    video_id: str
    calibration: CalibrateResponse
    fps_override: float | None = None
    frame_step: int = 1      # örnekleme: her N. kare (donanım uyarlaması)
    model_size: str = "nano" # "nano" | "small" | "medium"

class JobStatus(BaseModel):
    job_id: str
    state: str               # "queued" | "running" | "done" | "error"
    progress_pct: float
    eta_s: float | None
    error: str | None
```

## Ön Yüz: Tek Sayfa, Çok Adımlı Arayüz

### Adım 1 — Video Yükle
- Sürükle-bırak veya dosya seçici.
- Yükleme sonrası FPS + çözünürlük gösterilir.
- "Yanlış görünüyorsa FPS'i düzelt" alanı.

### Adım 2 — Kalibrasyon Karesi Seç
- Kare numarası veya zaman (ss:dd) girişi.
- "←/→" tuşlarıyla kare kare gezinme.
- Seçili kare `<img>` olarak gösterilir.

### Adım 3 — Kontrol Noktaları
- Canvas üzerinde tıklama → sarı daire + numara.
- Her noktanın gerçek dünya koordinatı yan tabloda girilir.
- "Preset: Şerit genişliği 3.5 m" butonu — yaygın kullanım için kısayol.
- "M6 Otomatik Öner" butonu → `/api/video/{vid}/autoref` çağrısı → öneriler turuncu ile
  gösterilir; her biri onay kutusundan onaylanır.
- Nokta sürüklenebilir (sub-pixel hassasiyet için).
- Canlı RMS kutusu: her değişiklikte `/api/calibrate` çağrısı → RMS anında güncellenir.
  Renk kodu: yeşil (< 0.05 m), turuncu (< 0.20 m), kırmızı (≥ 0.20 m).

### Adım 4 — Saha Ölçümü (Opsiyonel)
- "Saha ölçümü ekle" butonu → noktaları `site_measurement` kaynağıyla güncelleme.
- Güven seviyesi göstergesi güncellenir.

### Adım 5 — Pipeline Başlat
- Model boyutu seçici (nano/small/medium).
- Kare adımı seçici (1 = her kare, 2 = her ikinci kare, …).
- GPU/CPU bilgisi (otomatik algılama sonucu gösterilir).
- "İşle" butonu → `/api/pipeline` POST → ilerleme çubuğu + ETA.

### Adım 6 — Sonuçlar
- Hız tablosu: araç ID, sınıf, hız km/h, güven aralığı, güven seviyesi.
- Overlay video `<video>` elemanında oynatılır.
- "Raporu İndir (PDF)" ve "Overlay Video İndir" butonları.
- "Yeni analiz" butonu → 1. adıma döner.

## Güvenlik (yerel servis için)

- Sunucu yalnızca `127.0.0.1` adresini dinler — ağ üzerinde erişilemez.
- Yüklenen dosyalar geçici dizine (`tempfile.mkdtemp`) yazılır; oturum kapanınca temizlenir.
- Dosya adı sanitasyonu: `pathlib.Path(filename).name` ile traversal önlenir.
- Upload boyutu sınırı: maksimum 10 GB (yapılandırılabilir).
- CORS: yalnızca `127.0.0.1` origin'ine izin verilir.

## Başlatıcı (launcher.py)

```python
import subprocess, webbrowser, time, sys, socket

PORT = 8742

def _port_free(port: int) -> bool:
    with socket.socket() as s:
        return s.connect_ex(("127.0.0.1", port)) != 0

def main():
    proc = subprocess.Popen(
        [sys.executable, "-m", "uvicorn", "src.ui.app:app",
         "--host", "127.0.0.1", "--port", str(PORT)],
    )
    # Sunucu hazır olana kadar bekle (max 15 sn)
    for _ in range(30):
        if not _port_free(PORT):
            break
        time.sleep(0.5)
    webbrowser.open(f"http://127.0.0.1:{PORT}")
    try:
        proc.wait()
    except KeyboardInterrupt:
        proc.terminate()

if __name__ == "__main__":
    main()
```

## PyInstaller Paketi

```bash
# Geliştirme ortamında çalıştır:
pyinstaller \
  --name SpeedDetection \
  --onedir \
  --add-data "src/ui/static:src/ui/static" \
  --add-data "src:src" \
  src/ui/launcher.py
```

- `dist/SpeedDetection/` klasörü kuruluma hazır. Windows'ta `.msi` wrapper opsiyonel.
- Model ağırlıkları (`yolo11n.pt`) ilk çalıştırmada indirilir; offline kurulum için
  `add-data` ile pakete gömülür (boyut ~6 MB, kabul edilebilir).
- `--onefile` değil `--onedir`: çıkarma süresi yok, daha hızlı başlangıç.

## Kabul Testleri (Definition of Done)

### API Testleri (`test_ui_api.py`, `httpx.AsyncClient` / `TestClient`)

1. **Video yükle — meta veri doğru:**
   Geçerli `.mp4` yükle → `video_id` döner, `fps` > 0, `sha256` 64 karakter.

2. **Kare döndürme:**
   `GET /api/video/{vid}/frame/0` → HTTP 200, `Content-Type: image/jpeg`.

3. **Geçersiz kare numarası:**
   `frame_count` + 1 istenmesi → HTTP 422 veya 404.

4. **Kalibrasyon — 4 nokta, geçerli:**
   4 non-kollinear nokta çifti → `rms_m` > 0, `inlier_count` == 4,
   `homography` 3×3 liste.

5. **Kalibrasyon — 3 nokta, yetersiz:**
   3 nokta → HTTP 422 (yeterli nokta yok).

6. **AutoRef uç noktası:**
   Şerit içeren sentetik kare + video_id → `proposals` listesi döner (boş bile olsa).

7. **Pipeline başlatma — `job_id` döner:**
   Geçerli `PipelineRequest` → `{job_id: ...}` içeren 202 yanıt.

8. **Job status — geçersiz ID:**
   Bilinmeyen `job_id` → HTTP 404.

9. **Statik dosya serve:**
   `GET /` → `index.html` içeriği, HTTP 200.

10. **Upload boyutu aşıldı:**
    10 GB + 1 bayt gönder → HTTP 413.

### Manuel Testler (CI dışı)

11. **Uçtan uca akış — gerçek video:**
    Gerçek trafik videosu yükle → kalibrasyon yap → pipeline başlat → overlay video ve PDF
    indirilir, PDF içinde hız tablosu ve RMS değeri görünür.

12. **Başlatıcı:**
    `python -m src.ui.launcher` → tarayıcı otomatik açılır, `127.0.0.1:8742` yüklenir.

13. **PyInstaller paket:**
    `dist/SpeedDetection/SpeedDetection` çalıştırılır → UI açılır, video yüklenebilir.
