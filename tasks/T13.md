## Bağlam

Ana sonuç tablosunda her track için tek bir `speed_kmh` (medyan) gösteriliyor. Araç sahnede
hız değişimi yaşıyorsa (kaza senaryolarında tipik: hızlı giriş → frenleme → durma) bu tek sayı
ne maksimum hızı ne de çarpışma anındaki hızı gösteriyor. Adli açıdan en kritik olan,
çarpışma öncesi hızdır — medyan bunu gizleyebilir.

## Kapsam

**İçinde:**
- `GET /api/job/{job_id}/track/{track_id}/speed-series` — yeni endpoint, `smoothed_series`
  döner: `[{t_s, speed_kmh}]`.
- Ana sonuç tablosunda her satıra hover ile açılan mini SVG sparkline (harici kütüphane yok).
- Sparkline'da: zaman ekseni (saniye), hız ekseni (km/h), max hız ve medyan çizgisi.

**Dışında:**
- `result_data.json` yoksa (eski iş) endpoint 404 döner, hover çalışmaz — graceful.
- PDF raporuna ekleme (ayrı görev gerekirse).
- Tam boyutlu interaktif grafik (tooltip, zoom vb.) — sadece mini sparkline.

### Backend endpoint

```python
@app.get("/api/job/{job_id}/track/{track_id}/speed-series")
async def speed_series(job_id: str, track_id: int) -> SpeedSeriesOut:
    _get_done_job(job_id)
    out_dir = _job_out_dir(job_id)
    rd = read_result_data(out_dir)          # result_data.json
    for est in rd.speed_estimates:
        if est.track_id == track_id:
            return SpeedSeriesOut(
                track_id=track_id,
                points=[{"t_s": t, "speed_kmh": v} for t, v in est.smoothed_series],
                max_kmh=max(v for _, v in est.smoothed_series),
                median_kmh=float(np.median([v for _, v in est.smoothed_series])),
            )
    raise HTTPException(404, "Track bulunamadı.")
```

### Frontend sparkline

Tablo satırına hover (ya da tıklama) eklenir → `useQuery(['speedSeries', jobId, trackId])` ile
seri çekilir → `SpeedSparkline` bileşeni saf SVG path ile çizer.

Sparkline boyutu: ~200×60 px, satır içi açılan küçük kutu. Karmaşık etkileşim yok.

```
│ Takip │ Sınıf │     Hız (km/h) ▼    │ ...
│  #3   │  car  │  16.0  [~~~∧~~~\__] │ ...
                          ↑ hover sparkline
```
