# M2 — Tespit + Takip

> **Durum:** Beklemede. M1 bittikten sonra aktif olur.
> Anayasa: `CLAUDE.md`. Mimari gerekçe: `docs/teknik-analiz.md` §6.

## Amaç
Bir video dosyasından, her karedeki araçları tespit eden ve kareleri aşarak her aracı
aynı `track_id` ile izleyen modül. Çıktı: her araç için **piksel yörüngesi** (temas
noktaları dizisi). Hız hesabı yok — o M3'te.

## Kapsam
**İçinde:** YOLO ile araç tespiti, ByteTrack/BoT-SORT ile takip, temas noktası hesabı
(bbox alt-orta), oklüzyon tespiti, veri sınıfları, birim testleri, `ultralytics` pin.
**Dışında:** Hız/metrik hesabı (M3), kalibrasyon (M1), video yazma/overlay (M5).
Segmentasyon/keypoint tabanlı temas noktası iyileştirmesi (ileride, M3+ sonrası opsiyonel).

## Veri Sınıfları ve Fonksiyon İmzaları
Tip ipuçları zorunlu. Birimler: piksel `(u, v)`.

```python
# models.py
VEHICLE_CLASSES = {"car", "truck", "bus", "motorcycle"}

@dataclass
class Detection:
    frame: int
    bbox: tuple[float, float, float, float]  # (x1, y1, x2, y2)
    cls: str                                  # "car" | "truck" | "bus" | "motorcycle"
    confidence: float

@dataclass
class TrackPoint:
    frame: int
    t_s: float                               # frame / fps
    contact_pixel: tuple[float, float]       # temas noktası: ((x1+x2)/2, y2)
    bbox: tuple[float, float, float, float]

@dataclass
class Track:
    track_id: int
    vehicle_class: str
    points: list[TrackPoint]
    occlusion_gaps: list[tuple[int, int]]    # (gap_start_frame, gap_end_frame)

# video.py
@dataclass
class VideoMeta:
    fps: float
    frame_count: int
    width: int
    height: int
    fps_source: Literal["container"]         # operatör override M3/UI'de eklenecek

def read_video_meta(video_path: str | Path) -> VideoMeta:
    """OpenCV ile FPS, çözünürlük, kare sayısını oku."""

def iter_video_frames(
    video_path: str | Path,
    frame_step: int = 1,
) -> Iterator[tuple[int, np.ndarray]]:
    """(frame_idx, bgr_frame) üret. frame_step ile örnekleme yapılabilir."""

# detector.py
class YOLODetector:
    def __init__(
        self,
        model_name: str = "yolo11n.pt",
        device: str = "auto",              # "auto" → GPU varsa cuda, yoksa cpu
        conf_threshold: float = 0.25,
    ) -> None: ...

    def detect_frame(self, frame: np.ndarray, frame_idx: int) -> list[Detection]:
        """YOLO ile tek kare tespiti. Sadece VEHICLE_CLASSES döndürülür."""

# tracker.py
class VehicleTracker:
    def __init__(
        self,
        model_name: str = "yolo11n.pt",
        device: str = "auto",
        conf_threshold: float = 0.25,
        tracker_config: str = "bytetrack.yaml",  # veya botsort.yaml
    ) -> None: ...

    def process_video(
        self,
        video_path: str | Path,
        frame_step: int = 1,
    ) -> tuple[list[Track], VideoMeta]:
        """Videoyu işle, tüm araç track'lerini ve video meta bilgisini döndür."""
```

## Algoritma Notları

### Model seçimi
- Başlangıç modeli: `yolo11n.pt` (nano — CPU için en hızlı, yeterli doğruluk).
- Model ilk çalıştırmada Ultralytics cache'inden otomatik indirilir.
- Sürüm `requirements.txt`'e pinlenir (ilk çalışan stabil sürüm).

### `device="auto"` mantığı
```python
import torch
device = "cuda" if torch.cuda.is_available() else "cpu"
```

### Temas noktası (kritik)
```python
contact_pixel = ((x1 + x2) / 2, y2)  # bbox alt-orta noktası
```
Bbox merkezi `(cx, cy)` KULLANILMAZ — paralaks hatası üretir (bkz. `docs/teknik-analiz.md` §6.3).

### Oklüzyon tespiti
Track'in kaydettiği ardışık kareler arasındaki boşluk → `occlusion_gaps`.
```python
frames = [p.frame for p in track.points]
gaps = [(frames[i]+1, frames[i+1]-1)
        for i in range(len(frames)-1)
        if frames[i+1] - frames[i] > 1]
```
Bu bilgi M4'te track kalite skoru için kullanılır.

### Sınıf filtresi
Ultralytics COCO sınıf adlarından yalnızca `VEHICLE_CLASSES` geçirilir;
diğer tespitler (insan, bisiklet vb.) sessizce atılır.

## Kabul Testleri (Definition of Done)

1. **Temas noktası doğruluğu:** Verilen `(x1, y1, x2, y2)` bbox'tan temas noktasının
   `((x1+x2)/2, y2)` olduğu doğrulanır. (UI/video gerektirmez, saf hesap testi.)

2. **Sınıf filtresi:** `VEHICLE_CLASSES` dışındaki tespit (ör. "person") bir `Track`'e
   dönüşmez.

3. **Sentetik video — okuma:** OpenCV ile üretilmiş 30 karelik minimal video
   `iter_video_frames` ile başarıyla okunur; dönen kare sayısı ve boyutlar doğrulanır.

4. **Sentetik video — takip:** Üretilen videoda hareket eden bir dikdörtgen (sahte araç)
   `VehicleTracker` tarafından en az 1 `Track` olarak döndürülür ve track'in ≥2 `TrackPoint`'i
   olmalıdır. *(Model gerçek bir tespiti bulamazsa mock ile test edilir — bkz. not.)*

5. **Oklüzyon gap:** Kare listesinde boşluk olan bir `Track` üzerinde `occlusion_gaps`
   doğru aralıkları döndürür.

6. **VideoMeta okuma:** Gerçek ya da sentetik bir video dosyasından `fps`, `frame_count`,
   `width`, `height` doğru okunur.

7. **`device="auto"` güvenli çalışır:** GPU olmayan ortamda `YOLODetector` ve
   `VehicleTracker` hata vermeden başlatılır (CPU'ya düşer).

> **Sentetik video notu:** Gerçek YOLO tespiti için `yolo11n.pt` modelinin indirilmesi
> gerekir; CI/offline ortamda bu mümkün olmayabilir. Bu durumda Kabul Testi 4,
> `YOLODetector.detect_frame` monkeypatched/mock edilerek test edilebilir. Fakat gerçek
> modelle manuel çalıştırma da yapılmalıdır (aşağıdaki "demo" hedefi).
