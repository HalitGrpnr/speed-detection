## Bağlam

Mevcut `overlay.mp4` pipeline çalışınca bbox hızıyla üretilir ve sonradan güncellenemez.
Tekerlek hızı hesaplandığında sonuç tabloda güncelleniyor ama video değişmiyor.
Kullanıcı hem eski bbox videosunu hem yeni tekerlek hızı videosunu görmek istiyor.

## Kapsam

**İçinde:**
- `overlay.py::draw_frame()` ve `write_overlay_video()` — `speed_overrides` parametresi (belirli track için sabit hız göster)
- Yeni backend endpoint: `POST /api/job/{id}/track/{id}/wheel-overlay` — seçilen track'in hızı tekerlek değeriyle override edilmiş overlay üretir
- Yeni backend endpoint: `GET /api/job/{id}/track/{id}/wheel-overlay` — stream
- `WheelSpeedPanel` (SpeedResult bileşeni) — "Bu Hızla Overlay Oluştur" butonu
- `ResultsStep` — `wheelOverlays: Set<number>` state + overlay toggle (bbox ↔ tekerlek)

**Dışında:**
- Birden fazla track'in aynı anda tekerlek hızıyla overlay'e yansıtılması (sonraya)
- Asenkron/kuyruk tabanlı overlay üretimi (video kısa ise senkron yeterli)

## Teknik Yaklaşım

`draw_frame()` + `write_overlay_video()` → `speed_overrides: dict[int, float] | None` param.
O track için `_instant_speed()` yerine override değeri kullanılır (sabit, tüm karelerde).
Yeni overlay `overlay_wheel_{track_id}.mp4` olarak kaydedilir; bbox overlay dokunulmaz.

## Kabul Kriterleri

- [ ] Tekerlek hızı hesaplandıktan sonra "Overlay Oluştur" butonu görünüyor
- [ ] Overlay oluşunca ResultsStep'te video toggle'ı çıkıyor ("Bbox" | "Tekerlek #X")
- [ ] Bbox overlay değişmeden kalıyor (forensic bütünlük)
- [ ] `pytest` yeşil, `npm run build` temiz
