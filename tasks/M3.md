# M3 — Hız Hesabı

> **Durum:** Beklemede. M2 bittikten sonra aktif olur.
> Anayasa: `CLAUDE.md`. Mimari gerekçe: `docs/teknik-analiz.md` §7.

## Amaç
M1'den gelen **H matrisi** ile M2'den gelen **piksel yörüngelerini** birleştirip her araç için
**km/h cinsinden hız tahmini** üretmek. Çıktı: ham hız serisi + yumuşatılmış seri + nokta tahmini
+ güven aralığı. Güven seviyesi (high/medium/low) M4'te tam olarak oturtulacak; M3 iskeletini
kurar.

## Kapsam
**İçinde:** Track → metrik dönüşüm (H ile), anlık hız, kayan pencere yumuşatma (median / mean /
lineer regresyon eğimi), güven aralığı (spread-based), track kalite özeti, veri sınıfları,
birim testleri.
**Dışında:** Kalibrasyon (M1), tespit/takip (M2), overlay video / rapor (M5), düzlemsellik
kontrolü ve tam güven skoru (M4), UI (M7).

## Veri Sınıfları ve Fonksiyon İmzaları
Birimler: zaman saniye (`t_s`), hız km/h, mesafe metre.

```python
# models.py
@dataclass
class SpeedSample:
    frame: int
    t_s: float                          # kare / fps
    world_m: tuple[float, float]        # H ile dönüştürülmüş (X, Y) metre
    speed_kmh: float                    # ardışık iki örnek arası anlık hız

@dataclass
class TrackQuality:
    frame_count: int
    has_occlusion: bool                 # occlusion_gaps listesi boş değilse True
    smoothness_residual: float          # yumuşatılmış seri residual'larının RMS (km/h)

@dataclass
class SpeedEstimate:
    track_id: int
    value_kmh: float                    # nokta tahmini (yumuşatılmış serinin medyanı)
    ci_kmh: float                       # ± güven aralığı (IQR/2 veya ±1σ)
    confidence_level: Literal["high", "medium", "low"]   # M4'te detaylandırılacak; M3 iskeleti
    speed_series: list[SpeedSample]     # ham anlık hız serisi
    smoothed_series: list[tuple[float, float]]  # [(t_s, smoothed_kmh)]
    track_quality: TrackQuality

# calculator.py
def track_to_world(
    track: Track,
    H: np.ndarray,
    fps: float,
) -> list[SpeedSample]:
    """Her temas noktasını H ile metrik konuma çevir; ardışık çiftler arası anlık hız hesapla.
    İlk nokta için speed_kmh = 0.0 (önceki nokta yok).
    Birden fazla kare atlandıysa (gap) Δframe / fps ile doğru Δt kullanılır."""

def estimate_speed(
    track: Track,
    H: np.ndarray,
    fps: float,
    window_s: float = 0.4,
    method: Literal["median", "mean", "regression"] = "median",
) -> SpeedEstimate:
    """Tam pipeline: track → metrik → ham seri → yumuşatma → SpeedEstimate.
    track_to_world → sliding_window_smooth → medyan/IQR → confidence_level iskeleti."""

# smoother.py
def sliding_window_smooth(
    samples: list[SpeedSample],
    window_s: float,
    method: Literal["median", "mean", "regression"] = "median",
) -> list[tuple[float, float]]:
    """Kayan pencere (window_s saniye genişliğinde) ile ham hız serisini yumuşat.
    Her çıktı noktası için penceredeki örnekler toplanır:
      median    → pencere medyanı
      mean      → pencere ortalaması
      regression → penceredeki t_s ~ speed_kmh çiftine doğrusal fit, t noktasındaki değer
    Dönüş: [(t_s, smoothed_kmh)] — uzunluk girdiyle aynı."""
```

## Algoritma Notları

### Metrik dönüşüm ve anlık hız
```python
# Her nokta için:
world = pixel_to_world(H, track_point.contact_pixel)   # → (X, Y) metre

# Ardışık iki nokta arası:
delta_d = sqrt((X2-X1)**2 + (Y2-Y1)**2)               # metre
delta_t = (frame2 - frame1) / fps                      # saniye  ← frame farkını kullan, 1/fps değil
speed_ms = delta_d / delta_t
speed_kmh = speed_ms * 3.6
```

`delta_t = 1/fps` **DEĞİL**, `delta_frame / fps`. Oklüzyon boşluğu veya frame_step varsa bu
fark kritik — yanlış Δt, hızı katlarla saptırır.

### Kayan pencere yumuşatma
Tek kare farkı çok gürültülüdür (tespit jitter, piksel yuvarlama). 0,3–0,5 saniyelik pencere
önerilir; yapılandırılabilir olmalı.

```
regression seçeneği: scipy.stats.linregress(t_window, v_window) → eğim değil, t noktasındaki
tahmin değeri kullanılır (kesişim + eğim × t). Eğim m/s² cinsinden ivmeye de erişim sağlar
(ileride kullanılabilir).
```

### Güven aralığı (M3 basit versiyonu)
```python
ci_kmh = np.percentile(smoothed_values, 75) - np.percentile(smoothed_values, 25)  # IQR
# veya: ci_kmh = smoothed_values.std() * 1.0
```
M4'te kalibrasyon RMS ve track kalitesiyle entegre edilecek; M3'te spread-based yeterli.

### confidence_level iskeleti (M4'e hazır yer tutucu)
```python
# M3'te basit kurallar — M4'te genişletilecek:
if track_quality.frame_count >= 20 and not track_quality.has_occlusion:
    confidence_level = "medium"   # kalibrasyon kalitesi M4'te eklenecek
elif track_quality.frame_count >= 5:
    confidence_level = "low"
else:
    confidence_level = "low"
```
"high" seviyesi M4'te kalibrasyonla birlikte tanımlanacak.

### TrackQuality.smoothness_residual
Ham seri ile yumuşatılmış seri arasındaki farkların RMS'i:
```python
residuals = [s.speed_kmh - smoothed for s, (_, smoothed) in zip(samples, smoothed_series)]
smoothness_residual = sqrt(mean(r**2 for r in residuals))
```

## Kabul Testleri (Definition of Done)

1. **Sabit hız — doğruluk:** Bilinen `H` ile sabit hızda hareket eden sentetik track üret
   (ör. 60 km/h). `estimate_speed` → `value_kmh` 60'a yakın (< 1 km/h sapma).

2. **Ham seri doğruluğu:** `track_to_world` doğru Δt kullanıyor mu? Sabit hız + eşit kare
   aralığında tüm `speed_kmh` değerleri beklenen değere yakın.

3. **Δt hatası önlemi:** Frame_step=3 ile oluşturulmuş track'te Δt = 3/fps. `delta_t = 1/fps`
   kullansaydı hız 3x hatalı olurdu — testle doğrula.

4. **Yumuşatma gürültüyü azaltır:** Sabit hıza Gaussian gürültü eklenmiş ham serinin std'si,
   yumuşatılmış serinin std'sinden büyük olmalı.

5. **Üç method tutarlı:** median / mean / regression aynı sentetik seriyi ±5 km/h içinde
   tahmin eder.

6. **Duran araç ≈ 0 km/h:** Temas noktası değişmiyorsa `value_kmh` < 1.

7. **Kısa track güven seviyesi:** frame_count < 5 → `confidence_level == "low"`.

8. **Oklüzyon bayrağı:** `occlusion_gaps` dolu track → `has_occlusion == True`.

9. **CI hesaplanabilir:** `ci_kmh >= 0` ve gürültülü seride düşük-gürültülü seriden büyük.
