> **Durum:** Beklemede. M4 bittikten sonra aktif olur.

## Amaç
M1–M4'ün ürettiği verileri iki somut çıktıya dönüştürmek:
1. **Overlay video:** Her araç üzerinde bbox + track ID + hız (km/h) + güven rengi.
2. **Adli rapor (PDF):** Bilirkişi raporuna girebilecek, her adımı gerekçelendiren belge.

## Kapsam
**İçinde:** Overlay çizimi, video yazma, PDF raporu (ReportLab), tek komutla uçtan uca
pipeline, `PipelineResult` veri modeli, birim testleri.
**Dışında:** UI (M7), otomatik referans tespiti (M6). Raporun yasal geçerliliği (hukuki
danışman gerektirir — bkz. `docs/teknik-analiz.md` §15.3).

## Overlay Algoritması

### Aktif track tespiti
Bir track, `frame_idx` karesinde aktif sayılır eğer en son kaydedilen noktası
`frame_idx` ile `frame_idx - frame_step` arasındaysa (kapsayıcı):
```python
last_frame = track.points[-1].frame if track.points else -1
active = (frame_idx - frame_step) <= last_frame <= frame_idx
```

### Çizim sırası (her aktif track için)
1. Son noktanın `bbox`'ından `cv2.rectangle` — renk = `CONFIDENCE_COLORS[confidence_level]`
2. Track ID ve hız metni: `f"#{track_id} {value_kmh:.0f} km/h"` — bbox'ın üstüne
3. Güven seviyesi harfi: `H/M/L` — metnin yanına küçük etiket

### Video yazma
```python
fourcc = cv2.VideoWriter_fourcc(*"mp4v")
writer = cv2.VideoWriter(str(out_path), fourcc, fps, (width, height))
for frame_idx, frame in iter_video_frames(video_path):
    out_frame = draw_frame(frame, frame_idx, speed_estimates, frame_step)
    writer.write(out_frame)
writer.release()
```

## PDF Rapor İçeriği (zorunlu bölümler)

```
1. Başlık sayfası
   - Rapor tarihi ve süresi
   - Video dosya adı, çözünürlük, FPS, süre
   - İşleme parametreleri (model, frame_step)

2. Kalibrasyon Özeti
   - Kullanılan katman (standard_assumption / operator / site_measurement)
   - Re-projeksiyon RMS (metre ve santimetre)
   - Düzlemsellik uyarısı (var/yok)
   - Kontrol noktaları tablosu: ID | piksel | dünya_m | kaynak

3. Hız Sonuçları
   Tablo: Track ID | Araç tipi | Hız (km/h) | CI (±km/h) | Güven | Kare sayısı | Oklüzyon
   (frame_count < 5 olan track'ler "yetersiz veri" notu ile)

4. Güven Seviyesi Açıklaması
   - Eşik değerleri tablosu (high/medium/low kriterleri)
   - Bu rapordaki sonuçların hangi kriterlere dayandığı

5. Varsayımlar ve Sınırlamalar
   - Yol yüzeyinin düzlem kabul edildiği
   - Kalibrasyon referanslarının standart ölçülere dayandığı (site_measurement yoksa)
   - FPS kaynağı ve doğruluğu
   - Temas noktası yaklaşıklığı (bbox alt-orta)
   - Kamera sabitliği varsayımı
```

## Kabul Testleri (Definition of Done)

1. **Renk doğruluğu:** `draw_frame` yüksek güvenli track için yeşil, düşük için kırmızı
   piksel üretir (numpy array üzerinde renk doğrulanır).

2. **Hız metni:** `draw_frame` çıktısı, orijinal siyah kareyle aynı değil
   (bir şeyler çizildiği anlaşılıyor).

3. **Aktif track tespiti:** Karede son noktası `frame_idx - frame_step` öncesinde olan
   track çizilmez; son noktası `frame_idx` olan çizilir.

4. **Overlay video dosyası oluşur:** `write_overlay_video` çalışır, çıktı dosyası
   sıfırdan büyük boyutta yazılır.

5. **PDF dosyası oluşur:** `generate_report` çalışır, `.pdf` uzantılı dosya sıfırdan
   büyük boyutta yazılır.

6. **PDF zorunlu bölümleri içerir:** Dosya içeriği (metin olarak) "Kalibrasyon",
   "Hız", "Varsayımlar" anahtar kelimelerini barındırır.

7. **Pipeline uçtan uca çalışır:** `run_pipeline` bir video + kalibrasyon.json alıp
   `PipelineResult` döndürür; `speed_estimates` boş değil.

8. **Tek komut:** `python -m src.output.pipeline <video> calibration.json
   --out-video output.mp4 --out-report report.pdf --step 3` çalışır, iki dosya üretir.
