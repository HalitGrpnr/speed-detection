## Amaç
Şu ana kadar her modül kendi işini yaptı ama "bu hız tahminine ne kadar güvenilir?"
sorusuna sayısal bir cevap yok. M4, kalibrasyon kalitesini (M1'den), track kalitesini
(M2'den) ve hız serisinin pürüzsüzlüğünü (M3'ten) birleştirip her araç için
**savunulabilir bir güven seviyesi** üretir. Ayrıca yolun düzlük varsayımını sayısal
olarak sınar (düzlemsellik kontrolü).

## Kapsam
**İçinde:** Güven seviyesi hesabı (`high`/`medium`/`low`), eşik tablosu, düzlemsellik
kontrolü (kalibrasyon noktaları artıklarının derinlikle korelasyonu), M1 `planarity_warning`
alanını gerçekten doldurmak, `estimate_speed`'e `CalibrationResult` bağlamak, birim testleri.
**Dışında:** Overlay video / rapor (M5), UI (M7). Segmentasyon/keypoint tabanlı temas noktası
iyileştirmesi (ileride opsiyonel).

```python
@dataclass

    track_frame_count: int
    has_occlusion: bool
    smoothness_residual_kmh: float

def compute_confidence_level(signals: ConfidenceSignals) -> Literal["high", "medium", "low"]:
    """Sinyalleri tabloya göre birleştir → high/medium/low."""

# reliability/planarity.py
def planarity_check(
    H: np.ndarray,
    points: list[ControlPoint],
) -> tuple[bool, float]:
    """Kalibrasyon noktası artıklarının Y-derinliğiyle Pearson korelasyonu.
    Dönüş: (warning: bool, correlation: float)
    |correlation| > 0.7 → yol eğimi/kabarıklığı → warning=True."""
```

## Güven Seviyesi Eşik Tablosu (başlangıç — gerçek veriyle sıkılaştırılacak)

| Sinyal | high | medium | low |
|--------|------|--------|-----|
| `calibration_layer` | `site_measurement` | `operator` veya `site_measurement` | `standard_assumption` |
| `reprojection_rms_m` | < 0.05 m | < 0.20 m | ≥ 0.20 m |
| `track_frame_count` | ≥ 30 | ≥ 15 | < 15 |
| `has_occlusion` | False | — | — |
| `smoothness_residual_kmh` | < 5 | < 15 | ≥ 15 |

**Birleştirme kuralı:**
- Herhangi bir sinyal "low" sınırına düşerse → sonuç `low`.
- Tümü "high" sınırını karşılıyorsa → `high`.
- Geri kalan → `medium`.

`planarity_warning=True` ise güven seviyesi bir kademe düşer (`high`→`medium`, `medium`→`low`).

## Algoritma Notları

### Düzlemsellik kontrolü
```python
# Her kalibrasyon noktası için artık = pixel_to_world(H, nokta.pixel) - nokta.world_m
# residual_m[i] = sqrt(dx² + dy²)
# depth[i] = nokta.world_m[1]  ← Y ekseni = yol derinliği
# Pearson r(depth, residual_m)
# |r| > 0.7 → düzlemsellik uyarısı
from scipy.stats import pearsonr
correlation, _ = pearsonr(depths, residuals)
warning = abs(correlation) > 0.7
```

En az 4 nokta gerekir; daha az varsa `warning=False, correlation=0.0`.

### `compute_homography` değişikliği
M1'deki `CalibrationResult` her zaman `planarity_warning=False` döndürüyordu.
M4'te `compute_homography` şöyle değişir:
```python
from src.reliability.planarity import planarity_check
warning, _ = planarity_check(H, active)
return CalibrationResult(..., planarity_warning=warning)
```

## Kabul Testleri (Definition of Done)

1. **high koşulları:** `site_measurement` + RMS=0.03m + 40 kare + oklüzyon yok +
   residual 3 km/h → `compute_confidence_level` → `"high"`.

2. **standard_assumption → low:** `calibration_layer="standard_assumption"` olan
   her senaryoda sonuç `"low"`.

3. **Yüksek RMS → low:** `reprojection_rms_m=0.25` → `"low"`.

4. **Kısa track → low:** `frame_count=8` → `"low"`.

5. **Planarity düz:** Bilinen `H` ile aynı düzlemde 6 nokta → `warning=False`,
   `|correlation| < 0.5`.

6. **Planarity eğimli:** Artıklar derinlikle sistematik artıyorsa → `warning=True`.

7. **planarity_warning kademe düşürür:** `compute_confidence_level` `"medium"` üretecek
   sinyaller + `planarity_warning=True` → sonuç `"low"`.

8. **estimate_speed entegrasyonu:** M1 kalibrasyon + M3 hız + M4 güven zinciri uçtan uca
   çalışır; `SpeedEstimate.confidence_level` artık iskelet değil gerçek değer.

9. **M3 testleri hâlâ geçiyor:** `estimate_speed` imzası değişiyor ama geriye uyumlu
   test senaryoları korunur (kalibrasyon fixture eklenir).
