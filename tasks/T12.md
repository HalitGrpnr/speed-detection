# T12 — Dingil Karşılaştırmasında Pencere H-Hızı

> **Durum:** ✅ Bitti
> **Efor:** Küçük
> **Öncelik:** Yüksek
> **Oluşturulma:** 2026-09-10
> **Bağımlılık:** T8
> **Kaynak:** Kullanıcı testi — dingil panelindeki "H-tabanlı" karşılaştırma tüm track medyanını
> gösteriyor, oysa kullanıcı belirli bir pencereyi (60→0 km/h senaryosu) ölçüyor.

---

## Bağlam

`AxleSteppingPanel`'deki "H-tabanlı (karşılaştırma)" kutusu şu an `SpeedEstimateOut.speed_kmh`'ı
gösteriyor — tüm track boyunca medyan. Oysa dingil ölçümü yalnızca `frame_n`'den son adım
frame'ine kadar olan pencereyi kapsıyor. 60→0 km/h gibi bir senaryoda medyan 16 km/h, pencere
içi gerçek hız 50–60 km/h olabilir. Karşılaştırma aktif olarak yanıltıcı.

## Kapsam

**İçinde:**
- `/api/job/{job_id}/track/{track_id}/axle-step` response'una `h_speed_window_kmh` alanı ekle.
- Backend: `result_data.json` → ilgili track'in `smoothed_series` → `frame_n`..`son_adım_frame`
  aralığındaki örnekler → medyan.
- Frontend: karşılaştırma kutusunda `h_speed_window_kmh` kullan, başlık "H-tabanlı (aynı pencere)"
  olarak güncelle.

**Dışında:**
- `result_data.json` yoksa (eski iş) sessizce `null` döner, frontend mevcut medyanı gösterir.

## Teknik Analiz

### Etkilenen Dosyalar
- `src/ui/schemas.py` — `AxleStepResponse`'a `h_speed_window_kmh: float | None`
- `src/ui/app.py` — `axle_step` endpoint: `read_result_data` → track bul → pencere filtrele
- `frontend/src/lib/models.ts` — `AxleStepResponse`'a alan ekle
- `frontend/src/features/results/AxleSteppingPanel.tsx` — karşılaştırma kutusu güncelle

### Yaklaşım

Backend'de, axle-step endpoint adımları hesapladıktan sonra:

```python
window_start = req.frame_n
window_end = result.steps[-1].frame if result.steps else req.frame_n

# result_data.json'dan smoothed_series oku
rd = read_result_data(out_dir)
for est in rd.speed_estimates:
    if est.track_id == track_id:
        window_speeds = [
            v for (t_s, v) in est.smoothed_series
            if window_start / fps <= t_s <= window_end / fps
        ]
        h_speed_window = float(np.median(window_speeds)) if window_speeds else None
```

Frontend'de `hSpeedKmh` prop'u kaldırılır, `data.h_speed_window_kmh` kullanılır.
`ResultsStep.tsx`'te `hSpeedKmh={est?.speed_kmh ?? 0}` aktarımı kaldırılır.
