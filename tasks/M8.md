## Amaç
Mevcut "student project" seviyesindeki UI'ı (tek dosya `index.html` inline CSS + vanilla
`app.js`/`calibration.js`) modern, bileşen-tabanlı, tip-güvenli bir SPA'ya taşımak.
Ürün birilerine gösterilmeden önce cilalı ve sürdürülebilir bir frontend mimarisi kurmak.

## Kararlar (kullanıcı onaylı — detay `DECISIONS.md`)
- **Stack:** React 18 + TypeScript + Vite + Tailwind + shadcn/ui (agentic kodlamaya en uygun).
- **Tasarım:** Açık enterprise yüzey + mavi vurgu, **koyu kalibrasyon canvas'ı**.
- **Yaklaşım:** Kademeli. Önce shell + tasarım sistemi, sonra ekran ekran. Eski UI parite
  sağlanana kadar `/legacy`'de çalışır kalır (Step 8'de silinir).

## Mimari özeti
- `frontend/` (Vite+React+TS) → build çıktısı `src/ui/web/` → FastAPI servis eder + PyInstaller'a girer.
- Dev: `vite dev` (`/api` → uvicorn proxy, HMR) + ayrı `uvicorn src.ui.app:app --reload`.
- Tipler: `openapi-typescript` ile `/openapi.json`'dan üretilir (`schemas.py` tek doğruluk kaynağı).
- Server state: TanStack Query · Client/wizard state: Zustand · UI: shadcn/ui primitives.
- Forensic: Node yalnızca dev-time; runtime statik dosya, harici CDN yok, veri makineden çıkmaz.
