> **Durum:** Beklemede. M5 bittikten sonra aktif olur.

> kalır; M6 buna bir *kolaylık katmanı* ekler.

## Amaç
Operatörün kalibrasyon için elle tıkladığı kontrol noktalarını **otomatik olarak önermek**.
Sistem video karesindeki şerit kenarlarını ve kesik şerit çizgilerini tespit eder,
standart boyutlarla (şerit ~3,5 m, kesik çizgi ~3 m) dünyal koordinat önerir.
**Operatör onayı her zaman zorunludur — otomatik öneri asla son söz değildir.**

## Neden Kolaylık Katmanı, Ölçek Kaynağı Değil
§0(c)'den: Otomatik tespit saha ölçümünün yerine geçmez; standart referansı operatör
yerine işaretleyen bir araçtır. Tespit başarılı olsa da confidence_layer =
`"standard_assumption"` kalır — çünkü gerçek şerit genişliği 3,3 m ya da 4,0 m olabilir.
Saha ölçümü geldiğinde zaten mevcut mekanizmayla `"site_measurement"`'a yükseltilir.

## Kapsam
**İçinde:** Canny + Hough tabanlı şerit kenarı tespiti, kesik çizgi tespiti (Y-ölçek
tahmini için), `ProposedPoint` modeli, operatör incelemesi için görsel overlay, test seti.
**Dışında:** Plaka tespiti (ayrı model gerektirir — M6.5'e ertelendi), UI entegrasyonu
(M7), kalibrasyon JSON'ına otomatik yazma (operatör onayı olmadan).
**Yeni bağımlılık yok** — OpenCV zaten mevcut.

## Veri Modeli ve Fonksiyon İmzaları

```python
# models.py
@dataclass
class ProposedPoint:
    pixel: tuple[float, float]
    world_m: tuple[float, float]       # standart varsayıma dayalı dünya koordinatı
    detection_confidence: float        # 0.0–1.0 (hat uyum kalitesi)
    description: str                   # "left_lane_near", "right_lane_far", vb.

    def to_control_point(self, point_id: str) -> ControlPoint:
        """ControlPoint(source='auto') döndür — kalibrasyona doğrudan beslenebilir."""

# lane.py
def detect_lane_edges(
    frame: np.ndarray,
    roi_top_ratio: float = 0.45,      # üst %N'i yok say (gökyüzü, bina)
    canny_low: int = 50,
    canny_high: int = 150,
    min_line_length: int = 80,
    max_line_gap: int = 40,
) -> tuple[np.ndarray | None, np.ndarray | None]:
    """Sol ve sağ şerit kenarlarını tespit et (Canny + HoughLinesP).

    Dönüş: (left_pts, right_pts) — her biri y'ye göre sıralı (N,2) piksel dizisi.
    Tespit yoksa None.
    """

def fit_lane_line(
    points: np.ndarray,
) -> tuple[float, float] | None:
    """Şerit noktalarına y = mx + b doğrusu uydur. (m, b) veya None döndür."""

def sample_line_at_depths(
    m: float,
    b: float,
    y_pixels: list[float],
) -> list[tuple[float, float]]:
    """Verilen y piksel değerlerinde doğru üzerindeki (x, y) noktalarını döndür."""

# markers.py
@dataclass
class DashedMarker:
    start_pixel: tuple[float, float]
    end_pixel: tuple[float, float]
    length_px: float

def detect_dashed_markers(
    frame: np.ndarray,
    roi_top_ratio: float = 0.45,
    min_segment_px: int = 20,
    max_segment_px: int = 200,
) -> list[DashedMarker]:
    """Kesik şerit çizgisi segmentlerini tespit et.

    HoughLinesP çıktısından belirli uzunluk aralığındaki segmentleri filtrele.
    Türkiye standardı: ~3 m çizgi, ~6-9 m boşluk.
    """

def estimate_depth_scale(
    markers: list[DashedMarker],
    dash_length_m: float = 3.0,
) -> float | None:
    """Kesik çizgi uzunluğundan piksel/metre oranı tahmin et.

    Birden fazla marker varsa medyan al. Güvenilir tahmin için ≥3 marker gerekir.
    Dönüş: px/m (piksel başına metre) veya None.
    """

# proposer.py
class AutoProposer:
    def __init__(
        self,
        lane_width_m: float = 3.5,
        dash_length_m: float = 3.0,
        n_sample_depths: int = 3,
        roi_top_ratio: float = 0.45,
    ) -> None: ...

    def propose(
        self,
        frame: np.ndarray,
    ) -> list[ProposedPoint]:
        """Şerit tespiti + marker analizi → öneri kontrol noktaları.

        Başarılı senaryoda: sol şerit (x_world=0) ve sağ şerit (x_world=lane_width_m)
        üzerinde n_sample_depths derinlikte nokta çifti → 2×n_sample_depths öneri.
        """

    def draw_proposals(
        self,
        frame: np.ndarray,
        proposals: list[ProposedPoint],
    ) -> np.ndarray:
        """Önerileri kare üzerine çiz (operatör incelemesi için).

        Her nokta: daire + ID + dünya koordinatı etiketi.
        """
```

## Algoritma Detayı

### Şerit Kenarı Tespiti
```
1. Gri tonlamaya çevir → Gaussian blur (gürültü azaltma)
2. ROI maskesi: karenin alt (1 - roi_top_ratio) kısmı, trapez şeklinde
3. Canny kenar tespiti
4. HoughLinesP → line segment'ler
5. Her segment için eğim açısı filtrele: |angle| ∈ [20°, 80°] (yatay/dikey çizgileri at)
6. Görüntü orta çizgisine göre sol (negatif eğim) / sağ (pozitif eğim) grupla
7. Her grupta RANSAC ya da en çok oylanan (Hough vote) baskın doğruyu seç
8. Baskın doğru boyunca n_sample_depths eşit-aralıklı piksel örnekle
```

### Dünya Y Koordinatı Tahmini
```
Öncelik sırası:
1. Kesik çizgi tespiti başarılıysa (≥3 marker):
   - px/m = estimate_depth_scale(markers)
   - y_world = (y_px_ref - y_px) / px_per_m
   (y_px_ref = en yakın referans noktasının pikseli, y_world = 0)
2. Kesik çizgi yoksa (düz çizgi, gece, düşük kontrast):
   - Y değerleri rölatif tahminle atanır: y_world ∝ (y_vanish - y_px)
   - Vanishing point: sol+sağ şerit doğrularının kesim noktası
   - Ölçek: lane_width_m / (x_right_px - x_left_px) en yakın örnekte
   - Bu tahmin yaklaşık — raporda "auto_estimated" olarak işaretlenir
3. Her iki yöntem de başarısızsa:
   - Y = 0, 5, 10 m (varsayılan ızgara) ile öneri yapılır
   - description alanında "y_estimated" uyarısı taşır
```

### Dünya X Koordinatı
```
Sol şerit: x_world = 0
Sağ şerit: x_world = lane_width_m (varsayılan 3.5 m)
Şerit orta çizgisi tespit edilirse: x_world = lane_width_m / 2
```

## Kabul Testleri (Definition of Done)

1. **Şerit tespiti — sentetik kare:**
   Koyu zemin üzerine iki beyaz diyagonal çizgi çizilmiş 640×480 kare →
   `detect_lane_edges` sol ve sağ için `None` olmayan dizi döndürür.

2. **Boş kare — hiç çizgi yok:**
   Tamamen düz gri kare → `detect_lane_edges` `(None, None)` döndürür.

3. **Yatay çizgiler filtrelenir:**
   Yalnızca yatay çizgi içeren kare → `detect_lane_edges` `(None, None)` döndürür
   (açı filtresi çalışıyor).

4. **Doğru uydurma:**
   `fit_lane_line` ile y=2x+10 doğrusu üzerindeki noktalar → `(m≈2, b≈10)` döner.

5. **Kesik çizgi tespiti:**
   Belirli uzunlukta 3 segment içeren sentetik kare →
   `detect_dashed_markers` ≥3 `DashedMarker` döndürür.

6. **Derinlik ölçeği tahmini:**
   60 px uzunluğunda 3 marker, `dash_length_m=3.0` →
   `estimate_depth_scale` ≈ 60/3 = 20 px/m döndürür.

7. **ProposedPoint → ControlPoint dönüşümü:**
   `to_control_point("cp_auto_1")` → `ControlPoint(source="auto")` döner.

8. **Öneri confidence_layer:**
   `proposals[i].to_control_point(...)` ile oluşturulan noktalar
   `compute_homography` ile beslendiğinde `confidence_layer = "standard_assumption"`.

9. **draw_proposals çizim yapar:**
   `draw_proposals(black_frame, proposals)` → siyah kareyle birebir aynı değil.

10. **draw_proposals boş öneriyle — değişmez:**
    `draw_proposals(frame, [])` → orijinal kareyle aynı.

11. **AutoProposer uçtan uca:**
    Şerit içeren sentetik kare → `propose()` boş olmayan liste döndürür.

## Mevcut Sisteme Entegrasyon
`propose()` çıktısı doğrudan `make_calibration.py` veya `pick_points.py` akışına
beslenir:
```python
from src.autoref.proposer import AutoProposer
from src.calibration.homography import compute_homography

proposer = AutoProposer(lane_width_m=3.5)
proposals = proposer.propose(frame)

# Operatör onayı sonrası:
control_points = [p.to_control_point(f"cp_auto_{i}") for i, p in enumerate(proposals)]
result = compute_homography(control_points)
# result.confidence_layer == "standard_assumption"  ← otomatik tespit = düşük katman
```
